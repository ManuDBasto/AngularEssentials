Welcome to AngularEssentials

To start open your code editor and find the home component to understand how it works (src/app/features/home/). Access the Read me formore info.

This folder contains four files:

  • home.css: Control the styles from here.
  • home.HTML: Set the HTML tags for the UI and DOM.
  • home.spec.ts: Testing file.
  • home.ts: The most important, and the one that allows you to set variaZbles and functionality to the web using the TypeScript.

This is a component, each one of this files is binded together so you can start working on it without configuring something. You can learn how to create one in the read me.

Variables and functions:

Access to the home.ts file, to see how we set a variable: {{number}}. And we access to it using double brackets.

Also we can trigger functions using something like this counter:

{{counter}}

Navigation

This is a single page app, which means it is not loading files as pages when we navigate through the app, but instead the components are the ones changing and rotating in the app.

To set routes you need to go in the app.routes.ts file. And trigger the navigations trough links with RouterLink or with a function that triggers a navigation action.

Nav with link

The components are loaded in the location where the router-outlet tag is. In this case is in app.html.
